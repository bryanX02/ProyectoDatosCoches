# Predictor de Precios de Coches de Segunda Mano

Este proyecto desarrolla un sistema de aprendizaje automático diseñado para predecir los precios de coches de segunda mano, proporcionando así valor a plataformas de compraventa de vehículos, concesionarios y empresas de análisis de datos automotrices.

## Organización del Repositorio

La estructura del repositorio se divide en varias carpetas, reflejando las distintas etapas de procesamiento y análisis de datos:

- `adquisicion/`: Scripts y datos crudos obtenidos a través de web scraping.
- `exploracion/`: Análisis exploratorio de los datos recopilados.
- `limpieza/`: Procesamiento y limpieza de datos para prepararlos para el análisis.

## Objetivos

### Objetivo de Negocio
Optimizar la eficiencia de las plataformas de compraventa de vehículos, mejorando la precisión en la valoración de los vehículos.

### Objetivo del Sistema de Aprendizaje Automático
Mejorar la predicción de precios de coches de segunda mano mediante el análisis de datos históricos y tendencias del mercado.

## Uso del Sistema

El sistema está destinado a vendedores y compradores de vehículos de segunda mano, proporcionando valoraciones justas y realistas para mejorar la experiencia en la plataforma de compraventa de vehículos.
